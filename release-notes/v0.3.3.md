**Updates in the app:** Settings > About > Updates
- **Update channel:** Stable (tested releases) or Beta (betas too).
- **Check automatically:** each start, every hour, every 6 hours, daily, or only when you check.
- **Notify me about new versions:** a reminder each time the app starts, until you update.
- **Update** downloads and installs it:
  - **Android:** the installer opens. The first time, allow installs from the app; the install then carries on by itself.
  - **Windows:** the app closes, updates and opens again.

**MyAnimeList**
- **Your link follows your Jellyfin account:** link once, and it's there on every device you sign in on. Each Jellyfin user has their own link.
- **No client ID to paste:** it's built in.
- **A wrong client ID is caught** before the browser opens.

**Connections**
- **Errors say why:** for example, the name can't be found on this network, no answer in time, or an untrusted certificate.
- **Settings > Seerr** says when Seerr can't be reached. Your sign-in is kept.

**On phones:** tidier Settings rows (Check connection as an icon) and a shorter Seerr sign-in choice.
