## Kurage v0.3.7 beta 1: home and away

A beta: things to try before the next stable release. To get betas, choose **Beta** in **Settings > About > Update channel**.

### One server, more than one address
If you reach your server one way at home and another way when you're out (Tailscale, say, or a domain name), Kurage can now keep both and use whichever answers.

- **Add an address** in **Settings > Account & server > Server addresses**, or just sign in once through it: it joins the server you already have, for every account on it.
- **Each device keeps its own list,** so add the address once on each phone or PC you use (or sign in through it once there).
- **Home addresses come first** when both answer. The app picks again when it starts, when you refresh Home, when your network changes, when you come back to the app, and when the server stops answering.
- **Playback follows.** If the address in use stops answering mid-episode (Wi-Fi off, say), the player switches to one that answers and carries on from the same spot. Expect a short pause while the new network comes up. An address that still answers is never swapped mid-episode.

### Finding servers
- **The connect screen lists Jellyfin servers on your network,** found the way Jellyfin's own apps find them. Servers that don't answer this search (often ones running in Docker) can still be entered by address, as before.

### Also new
- **Refreshing Home checks for an app update** in the background (F5, Ctrl+R or pulling down), when automatic checks are on.
- **New installs start with the Depth theme.** If you already use Kurage, your theme stays as it is.

### Fixed
- **Seek previews that showed only the first picture** now follow the time. This happened when the server counted fewer thumbnails than the episode needs.
- **Settings > Seerr says when Seerr can't be reached,** instead of showing "Signed in as …" as if all were well. Your sign-in is kept for when it's back.
- **A failed update download** now gives a short message that fits its box, with the details in Settings > App log.

> **Android TV:** the Android app installs and runs on Android TV, but its TV layout **hasn't been tested yet**.
